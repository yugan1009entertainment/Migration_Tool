### 7.0 LOD Pattern Reference

| Tableau LOD Pattern | Power BI DAX Equivalent |
|---|---|
| {FIXED dim : COUNTD(expr)} | CALCULATE(DISTINCTCOUNT(col), ALLEXCEPT(table,dim)) |
| {FIXED dim : COUNTD(IF cond THEN expr END)} | CALCULATE(DISTINCTCOUNT(col), ALLEXCEPT(table,dim), filter condition) |
| COUNTD(IF date={FIXED REMS:MIN(IF cond)} THEN REMS END) | FILTER(VALUES(PatID), PSFDate=CALCULATE(MIN,ALLEXCEPT,condition)) |
| {FIXED dim : MAX(expr)} | CALCULATE(MAX(col),ALLEXCEPT(table,dim)) |
| expr/TOTAL(COUNTD(expr)) | DIVIDE([measure], CALCULATE([measure],ALL or ALLSELECTED)) |
| {FIXED dim : COUNTD(expr)}/SUM({FIXED}) | DIVIDE([measure], CALCULATE(DISTINCTCOUNT,ALLEXCEPT(table,dim))) |

## 16. TMDL Authoring Rules

Validated from: powerbi_complete_reference_1.txt, session error log

| Rule | Area | Rule Description |
|---|---|---|
| R01 | Relationships | Use fromColumn/toColumn with Table.Column notation. fromTable and toTable are NOT valid TMDL properties. |
| R02 | Object blocks | No blank lines inside any object block. No comment lines inside any object block. |
| R03 | database.tmdl | Only compatibilityLevel and annotation are allowed. Never hand-author; use Desktop-generated file only. |
| R04 | model.tmdl | Contains model properties and annotations only. No table blocks. Desktop-write-only. Only add annotation lines after model loads in Desktop. |
| R05 | Calculated columns | Inline = on the declaration line. NEVER use standalone expression property. Example: `column Age = Dispense[Age Days] / 365.25` |
| R06 | Measures | Inline = on the declaration line. NEVER use standalone expression property. Multi-line DAX uses indented block after = |
| R07 | Partition type | Calculated partitions: type = calculated (NOT dax). Calculated partitions have NO mode property. |
| R08 | Culture/collation | Never hand-author culture or collation lines. Only Desktop-generated shell is valid. Hand-authored model.tmdl triggers fatal error: "Culture and Collation properties may be changed only before any other object has been created." |
| R09 | PBIP injection order | 1. Delete working folder 2. Open Desktop > New > Save As .pbip > Close Desktop 3. Delete sample tables from tables\ folder 4. Copy tables/*.tmdl and relationships.tmdl only 5. Do NOT touch model.tmdl or database.tmdl 6. Open PBIP in Desktop |
| R10 | sortByColumn | Must reference a column in the same table. changedProperty = SortByColumn line required. |
| R11 | isHidden columns | Use isHidden keyword on its own line inside column block. |
| R12 | Parameter tables | annotation TableType = ParameterTable required. annotation PBI_NavigationStepName = Navigation required. annotation PBI_ResultType = Table required. |
| R13 | Calculated partition | source block uses DAX directly. No mode property. No m keyword. Example: `partition PartName = calculated` / `source = GENERATESERIES(0,35,1)` |
| R14 | M partition | `partition PartName = m` / `mode: import` / `source = ``` ... ``` ` |
| R15 | RELATED() | Requires active relationship between tables. DoseDim→Dispense and DoseDim→Dosing Data relationships must exist before RELATED(DoseDim[DoseSort]) resolves without error. |
| R16 | ALLEXCEPT vs ALLSELECTED | ALLEXCEPT preserves all filters except specified columns. ALLSELECTED respects slicer context. Choose based on whether parameter table slicers should affect the measure filter context. |
| R17 | DIVIDE vs division | Always use DIVIDE(numerator,denominator,0) for ratios. Direct division [a]/[b] errors on zero denominator. |
