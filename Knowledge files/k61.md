PBI Table Name             : Executive Tonnage View
PBI Load Mode              : Import (Value.NativeQuery, EnableFolding=true)

PBI Native SQL (preserved — key elements):
──────────────────────────────────────────
SELECT A.\*,
B.PARENT\_WAREHOUSE\_ID,
B.WAREHOUSE\_NAME AS WAREHOUSE\_NAME\_DIM\_WAREHOUSE,
B.EWM\_GOLIVE\_INDICATOR,
C.CUSTOMER\_ID AS CUSTOMER\_ID\_DIM\_CUSTOMER,
C.LEGACY\_CUSTOMER\_ID,
C.PARENT\_CUSTOMER\_NAME AS PARENT\_CUSTOMER\_NAME\_DIM\_CUSTOMER,
C.CUSTOMER\_NAME AS CUSTOMER\_NAME\_DIM\_CUSTOMER,
C.CUSTOMER\_STATUS,
C.PHENIX\_MIGRATION\_DATE
FROM "TRANSFORM"."EXECUTIVE\_TONNAGE\_VIEW" A
LEFT JOIN "CDW"."USCOLD"."DIM\_WAREHOUSE" B
ON A.PLANT\_ID = B.WAREHOUSE\_ID
AND B.ACTIVE\_RECORD\_INDICATOR = 'Y'
AND B.DELETE\_RECORD\_INDICATOR = 'N'
LEFT JOIN "CDW"."USCOLD"."DIM\_CUSTOMER" C
ON A.PLANT\_ID = C.WAREHOUSE\_ID
AND (
(B.EWM\_GOLIVE\_INDICATOR = 'Y' AND A.SNAPSHOT\_DATE >= C.PHENIX\_MIGRATION\_DATE
AND A.CUSTOMER\_ID = C.CUSTOMER\_ID)
OR (B.EWM\_GOLIVE\_INDICATOR = 'Y' AND A.SNAPSHOT\_DATE < C.PHENIX\_MIGRATION\_DATE
AND A.CUSTOMER\_ID = C.LEGACY\_CUSTOMER\_ID)
OR (B.EWM\_GOLIVE\_INDICATOR = 'N' AND A.CUSTOMER\_ID = C.LEGACY\_CUSTOMER\_ID)
)
AND C.ACTIVE\_RECORD\_INDICATOR = 'Y'
AND C.DELETE\_RECORD\_INDICATOR = 'N'

* PARENT\_CUSTOMER\_NAME: "N/A" replaced with null

⚠️  EWM GO-LIVE LOGIC: The DIM\_CUSTOMER join uses a three-way OR condition
