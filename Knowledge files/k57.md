### CC-20 | HC Flag
─────────────────────────────────────────────────────────────
PBI lineageTag  : 473e27e3-03d2-4035-9c44-d888c4048a01
PBI DataType    : string
PBI summarizeBy : none

Tableau Expression:

// No direct Tableau equivalent — PBI-only row-level variance flag

Power BI DAX:
─────────────
column 'HC Flag' =
VAR CurrentSite     = salmon_plm[Site 2]
VAR CurrentScenario = salmon_plm[Scenario 1]
VAR CurrentDept     = salmon_plm[Salmon Department Name]

VAR ActualHC =
    CALCULATE(
        MAX(salmon_plm[hc_value]),
        FILTER(
            salmon_plm,
            salmon_plm[Site 2]                  = CurrentSite     &&
            salmon_plm[Scenario 1]              = CurrentScenario &&
            salmon_plm[Salmon Department Name]  = CurrentDept     &&
            salmon_plm[hc_type]                 = "Actual HC"
        )
    )

VAR ModelHC =
    CALCULATE(
        MAX(salmon_plm[hc_value]),
        FILTER(
            salmon_plm,
            salmon_plm[Site 2]                  = CurrentSite     &&
            salmon_plm[Scenario 1]              = CurrentScenario &&
            salmon_plm[Salmon Department Name]  = CurrentDept     &&
            salmon_plm[hc_type]                 = "Model HC"
        )
    )

VAR PercentDifference =
    DIVIDE(
        ABS(ModelHC - ActualHC),
        ActualHC
    )

RETURN
    IF(
        PercentDifference > 0.1,
        "Flag",
        "OK"
    )

Depends on  : [Site 2], [Scenario 1], [Salmon Department Name],
              [hc_value], [hc_type] (all source columns)
Business Rule: Per (Site 2 / Scenario 1 / Salmon Department Name) grain,
               if |ModelHC − ActualHC| / ActualHC > 10%, return "Flag";
               else return "OK". DIVIDE() returns BLANK() if ActualHC = 0,
               so rows with zero actual HC will return BLANK() (not "OK").
               This is consistent behavior — confirm with data owner.
Type        : ➕ PBI-only
Conversion  : ✅ FULL

⚠️  RELATED TABLE: HC Flag Table (see PQ-08) is a DAX calculated table
    that replicates this same 10% threshold logic at the SUMMARIZE grain
    using simpler ADDCOLUMNS/SUMMARIZE pattern. Both coexist.
    The column-level version (CC-20) provides row-by-row flagging;
    the table-level version (PQ-08) provides a pre-aggregated summary.

─────────────────────────────────────────────────────────────

  // Sums [value] across the entire table partition

Power BI:
  CALCULATE(
      SUM('Table'[value]),
      ALLSELECTED('Table')

WHY: ALLSELECTED removes all visual cross-filters while respecting
     report-level slicers, approximating Tableau's table-scoped window.
     Used in: M-09 [Total PLM]; should be applied to M-08 [Total Headcount].

  DIVIDE(

      )
  )

Power BI (grand total, respects all slicers):
  DIVIDE(
      SUM('Table'[value]),
      CALCULATE(
          SUM('Table'[value]),
          ALLSELECTED('Table')
      )
  )
