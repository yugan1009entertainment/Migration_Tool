## 14. WRITEBACK ARCHITECTURE MAPPING

### 14.1 Tableau Writeback Pattern



User selects Cycle and Filters on dashboard
Tableau Extensions API captures current parameter state as JSON:
{"filters":{},"parameters":{}}
JSON payload written to param_writeback_test / param_writeback_version
Datasource filter on filter_parameter_set column routes the payload
to the correct row in SQL Server table tabwritebackprod
dp_hyperion_ibp_record_budget_proj_cycle_version (dbo schema)
and dp_hyperion_ibp_get_hyperion_planner_comments (GPS BIA schema)
are the read/write target tables
Subsequent reads filter the table by filter_parameter_set = param value


### 14.2 Power BI Writeback Pattern



param_writeback_test and param_writeback_version are ParameterTables
with a single static row containing {"filters":{},"parameters":{}}
Filtered at M query load time via UUID-based filter_parameter_set reference
dp_hyperion_ibp_record_budget_proj_cycle_version and
dp_hyperion_ibp_get_hyperion_planner_comments sourced from same SQL Server
Power BI does NOT natively write data back to SQL Server
Writeback requires: Power Automate flow, REST API call, or custom connector


| Feature                     | Tableau                            | Power BI                                 | Gap      |
