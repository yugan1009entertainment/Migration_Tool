─────────────────────────────────────────────────────────────

SELECT
ls\_apps.ACACTIVITY.ACTIVITY,
ACACTIVITY.DESCRIPTION AS ACTIVITY\_DESC,
ACACTIVITY.ACTIVITY\_GRP,
ACACTIVITY.COMPANY,
ACACTIVITY.PAR\_ACT\_STRCT\_01 as REGION,
ACACTIVITY.PAR\_ACT\_STRCT\_02 as WHS,
WHS.DESCRIPTION as WHS\_NAME,
ACACTIVITY.ACCT\_UNIT, ACCOUNT, SUB\_ACCT, ACCT\_CATEGORY,
CURRENCY\_CODE, USR\_STATUS, VAR\_LEVELS,
BEGIN\_DATE, END\_DATE, COM.START\_DATE,
ACACTIVITY.ACTIVE\_BUD, LONG\_DESC\_01,
ACACTIVITY.HIGH\_PST\_DATE as POSTING\_DATE,
ACACTIVITY.OBJ\_ID, PARENT\_ACTV,
isnull(ACACTIVITY.BALANCE\_AMOUNT,0) as ACTUAL\_AMOUNT,
ACACTIVITY.DATE\_CREATED,
MATRIX\_CAT\_ASSET.MX\_VALUE AS ASSETTYPE / DESCRIPTION,
MATRIX\_CAT\_BUDGET.MX\_VALUE AS BUDGETED\_YN,
MATRIX\_CAT\_MAJOR.MX\_VALUE AS MAJORCLASS / DESCRIPTION,
MATRIX\_CAT\_MINOR.MX\_VALUE AS MINORCLASS / DESCRIPTION,
ACACCTCAT.DESCRIPTION AS CATEGORY\_DESC,
isnull(ACBUDHDR.TOTAL\_BUDGET,0) as TOTAL\_BUDGET,
isnull(COM.AMOUNT,0) as COMMITTED\_AMOUNT
FROM ls\_apps.ACACTIVITY
LEFT JOIN ls\_apps.ACACCTCAT ON ACCT\_CATEGORY
LEFT JOIN ls\_apps.ACBUDHDR ON ACTIVITY
LEFT JOIN (SELECT ACTIVITY, SUM(BALANCE\_AMOUNT), MIN(MAINT\_DATE)
FROM ls\_apps.ACCOMMIT GROUP BY ACTIVITY) COM ON ACTIVITY
LEFT JOIN ACACTMXVAL+MXVALIDATE (ASSETTYPE) ON OBJ\_ID
LEFT JOIN ACACTMXVAL+MXVALIDATE (BUDGETED\_YN) ON OBJ\_ID
LEFT JOIN (ACACTIVITY WHERE LEVEL\_DEPTH=2, POSTING\_FLAG='S') WHS
ON LEFT(ACTIVITY,3)
LEFT JOIN ACACTMXVAL+MXVALIDATE (MAJORCLASS) ON OBJ\_ID
LEFT JOIN ACACTMXVAL+MXVALIDATE (MINORCLASS) ON OBJ\_ID
WHERE ACACTIVITY.POSTING\_FLAG = 'P'

p.ACCOUNTING\_PERIOD, SUM(p.PERIOD\_AMT) AS SPENT\_AMOUNT
FROM ls\_apps.ACGLMAST a
LEFT JOIN ls\_apps.ACACTIVITY a2 ON a.ACTIVITY = a2.ACTIVITY

─────────────────────────────────────────────────────────────
Tableau: IF \[WHS]='OMA260' THEN 'Omaha' ELSEIF '44501' THEN 'Cold Creek'
ELSE \[WHS\_NAME] END
PBI:     IF(\[WHS]="OMA260", "Omaha", IF(\[WHS]="44501", "Cold Creek", \[WHS\_NAME]))

PATTERN-02 | Region grouping via IN lists
─────────────────────────────────────────────────────────────
Tableau: 53 individual CASE WHEN clauses
PBI:     SWITCH(TRUE(), \[WHS\_NAME] IN {list}, "Region", ...)
WHY: Tableau CASE requires individual WHEN per value. DAX SWITCH + IN
consolidates to one clause per region.

PATTERN-03 | ZN() → COALESCE()
─────────────────────────────────────────────────────────────
Tableau: ZN(\[field]) — replaces null with 0
PBI:     COALESCE(\[field], 0) — same semantics

PATTERN-04 | Budget status 4-tier classification
─────────────────────────────────────────────────────────────
Tableau: nested IF/ELSEIF chain with SUM aggregation
PBI:     SWITCH(TRUE()) with VAR declarations for Budget/Spent/Remaining
WHY: DAX SWITCH with VARs is cleaner and avoids repeated SUM() calls.

PATTERN-05 | CONCATENATEX for multi-value column aggregation
─────────────────────────────────────────────────────────────
Tableau: Direct source column (one value per row from sqlproxy join)
PBI:     CONCATENATEX(FILTER(drilldown, ACTIVITY=EARLIER(ACTIVITY)),
\[column], ", ")
WHY: PBI model separates drilldown into its own table; CONCATENATEX
re-aggregates the 1:many values into a comma-separated string.

PATTERN-06 | Inline SVG bar chart in DAX measure
─────────────────────────────────────────────────────────────
PBI-only pattern: "data:image/svg+xml;utf8,<svg>...</svg>"
with dataCategory: ImageUrl. Generates proportional bar charts
entirely in DAX using DIVIDE(value, MAXX(ALLSELECTED, max\_value)).
Tableau: Uses native stacked/clustered bar chart visual.
